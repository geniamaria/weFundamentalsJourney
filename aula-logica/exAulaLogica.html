ha diferencia entre logica de programacao e linguagem de programacao.Dado o probrema a logica mostranos como resolver problemas ja a liguagem e a forma/ferramentas uadas para resolver um problemas

Os quantro pilares do pensamento computacional sao?

  • Decomposisao: Dado o problema grande antes de resolver vamos dividir o em problemas pequenos para facilitar a resolver
  • Reconhecimento de padoes: depois de dividir o problemas, vamos procurara ver quais tem membros/ou podem se resolver da mesma forma e agrupar os membros semelhantes
  • Abstracao: consiste em ignorar os aspectos irrelevantes para a resolucao do problemas, como por exemplo para calcular a media nao preciso de sabar a cor do cabelo do aluno
  • desenho do algoritmo: consite em descreve de forma sequeciada como proseguir para resolver o problema.
